## Day 1 & 2 - Networking Basics

### Things I learned

- IPv4 - Used for identifying devices and communicating over a network.
- Public and private IP - Public IP is used on the internet while private IP is used inside local networks.
- DNS - Helps convert website names into IP addresses.
- DHCP - Automatically assigns IP addresses and other network settings to devices.
- MAC address - An identifier of a network adapter.
- ARP - Helps find the MAC address of a device using its local IP address.
- Subnetting - Dividing a network into smaller networks.

### Practical on Windows

Commands covered in the networking lab:

- `getmac /v` - To check the MAC address of my network adapter.
- `arp -a` - To see the IP addresses and their corresponding MAC addresses.
- `route print` - To understand the routing table and default gateway.

### My understanding

At first I was a bit confused about why we need a MAC address when we already have an IP address. After learning about ARP, I understood that MAC addresses are needed for communication on the local network.

I also learned how the default gateway helps my PC communicate with networks outside my local network.

Still need more practice with subnetting.
